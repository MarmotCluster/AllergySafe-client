## Quick Tour

Allergy Safe is a online tool that **analyzes food ingredients** and notifies users of which ingredients cause their allergies.

<div>
  <img src="https://github.com/MarmotCluster/AllergySafe-client/assets/87087163/9fd4f09b-928f-42a3-a8f6-61619a603f7d" width="24%"/>
  <img src="https://github.com/MarmotCluster/AllergySafe-client/assets/87087163/87e8b4fe-7509-4501-96a2-38c257c333a4" width="24%"/>
  <img src="https://github.com/MarmotCluster/AllergySafe-client/assets/87087163/9fc61ab5-b455-4cf2-b9e9-b60ce40310a3" width="24%"/>
  <img src="https://github.com/MarmotCluster/AllergySafe-client/assets/87087163/8bcd2427-5a32-4fec-8839-a4e398e2602d" width="24%"/>
</div>

- scan a barcode mostly located behind the package of your food or you are able to type the numeric code yourself into the request. compare the ingredients to identify which ones trigger your allergic reactions.
- leave daily histories in your diary can be helpful to prevent from repeating.

  <img src="https://github.com/MarmotCluster/AllergySafe-client/assets/87087163/d5296909-6dde-4965-a252-403651267556" width="24%"/>

- understand how the allergic reactions that even you don't know are performing by detailed analytics.

## Technologies

- The web application is built with [Reactjs](https://react.dev/)
- The user interface designed with [MUI](https://mui.com/)

## Development

### requirements

- `Node.js`&nbsp; v17.0 or newer.
- `npm`&nbsp; v9.0 or newer.

### run it locally

locate into the project and run shell commands below.

```
npm install
npm start
```
